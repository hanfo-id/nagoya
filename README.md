# 겨울, 나고야

## 현재 일정 — 2026-11-07

12/12 토요일은 오스 관람·점심, 호텔 휴식, 17:30 스시 일정입니다. 12/13 일요일은 특급 히다로 게로 온천을 다녀옵니다. 12:30 오가와야 별관 유라기 대절탕과 15:32 복귀 열차를 계획하고, 나고야에서 19:15 몬자야키로 마무리합니다. 실제 예약은 앱의 예약 탭에서 별도로 기록합니다.

`node scripts/export-itinerary.cjs`로 앱 일정을 JSON으로 출력하고, `node scripts/build-guide.cjs`로 정적 전체 일정 문서를 생성합니다. 아래 이전 구현 설명과 QA는 작성 당시의 기록입니다.

2026년 12월 10–14일 4박 5일 나고야 여행을 위한 모바일 여행 노트입니다.

배포: https://hanfo-id.github.io/nagoya/

HTML/CSS/Vanilla JavaScript, GitHub Pages main 루트 배포입니다. 빌드 시스템·서버·DB·인증·API 키를 사용하지 않습니다.

## 주요 기능

여행 전 소개와 준비, 여행 중 일본 현지 날짜의 다음 행동을 우선합니다. 현장 화면 미리보기도 제공합니다. 공유 URL, 수동 날짜, 자동 날짜를 구분하며 ‘오늘’로 자동 선택에 돌아갑니다. 진행 상태는 수동 기록이며 시간이 지나도 완료 처리하지 않습니다.

일정과 지도는 식사·선택 방문·동물원 필터를 공유합니다. 번호 핀은 방문 순서이며 재방문에는 다른 번호가 붙을 수 있습니다. 핀의 위경도는 원본을 유지합니다. 겹치는 핀은 실제 장소 좌표에 놓인 장소 수 그룹을 눌러 고릅니다. 연결선은 표시하지 않습니다. 현재 위치에서의 길찾기와 출발지를 지정한 이전/다음 구간 길찾기를 구분합니다.

예약 가능 방식과 개인 예약 기록은 별개입니다. 확정 날짜·시각은 계획과 분리하며 전체 시간표를 자동 변경하지 않습니다. 첫날 지연 단축, 건너뛰기, 선택 방문 제외, 월요일 라멘 교체, 원복·직전 변경 되돌리기를 제공합니다.

## 저장과 백업

`nagoya26-v2`에 version 2 상태 하나를 저장합니다. 날짜·보기·필터·옵션·진행·예약·변경안·펼침·준비 체크·메모를 포함합니다. 기존 `nagoya26`는 보존하며 메모·선택·체크리스트를 마이그레이션합니다. 이전 예약 체크는 시각을 임의 생성하지 않고 재확인 메모를 붙여 가져옵니다.

손상된 새 저장 데이터는 가능한 경우 `nagoya26-v2-unreadable`에 보존합니다. 저장 실패 시 현재 세션과 JSON 내보내기를 제공합니다. JSON 가져오기는 형식·버전 검증과 덮어쓰기 확인을 거칩니다. 다른 기기와 자동 동기화되지 않으며 외부 예약·취소를 실행하지 않습니다.

예약 날짜·시간은 480px 이하에서 한 열로 표시합니다. 상단 다섯 메뉴에 예약을 포함하며, 관광지 추천 경험·사진 포인트·관련 작품은 공식 출처와 추천 의견을 구분합니다.

## 유지보수

```text
node scripts/build-guide.cjs
node tests/state.test.cjs
node tests/offline.test.cjs
python -m http.server 8766 --bind 127.0.0.1
```

원본 수정 시 정적 문서를 다시 생성합니다. 일반 배포에는 생성 명령이나 별도 빌드가 필요하지 않습니다. 배포 시 sw.js CACHE와 index 자산 버전을 함께 갱신합니다. ‘새 버전 적용’으로 Service Worker를 활성화하며 localStorage는 삭제하지 않습니다. 이전 앱 캐시만 정리하고 외부 지도 타일은 캐싱하지 않습니다.

오프라인은 최초 온라인 방문과 핵심 파일 저장 완료 이후 지원합니다. 외부 지도·예약·원격 웹폰트는 인터넷이 필요할 수 있습니다. 저장 삭제·시크릿 모드·브라우저 정책에 대비해 JSON 백업을 권장합니다.

Leaflet 1.9.4 라이선스는 vendor/leaflet에 있습니다. OSM 장소 좌표와 국토지리원(GSI) 주소 검색 결과를 위경도로 가공했습니다. 주소·구역 중심점은 실제 출입구와 차이가 있습니다.

사실 정보 확인일은 2026-11-05입니다. 이번 UX 개편에서 운영시간·가격·계획 시각을 새로 확정하거나 변경하지 않았습니다. 실제 티켓·예약·영업·교통 상황은 외부 공식 안내가 우선합니다.

이번 품질 개선: components.css가 내비게이션·버튼·예약 폼·지도 목록을 담당합니다. 기존 네 CSS 파일에서 해당 선택자를 제거했습니다. place-experiences.js에 13개 관광지 콘텐츠와 공식 출처가 있습니다. node tests/map-coordinates.test.cjs는 좌표 불변성을 검증합니다.
