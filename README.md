# 겨울, 나고야

2026년 12월 10–14일 4박 5일 여행 계획. 평일 인기 맛집과 주말 관광을 중심으로 작성했습니다.

- `index.html`: 웹 페이지
- `style.css`: 반응형·인쇄 스타일
- `app.js`: 상세 일정, 식당 예약 정보, 검색·필터·브라우저 저장

모든 예약은 방문 제안이며 실제 예약을 대신하지 않습니다. 정보 확인일: 2026-11-05. 출처는 웹사이트 안에 포함되어 있습니다.

GitHub Pages는 main 브랜치의 루트에서 자동 게시됩니다: https://hanfo-id.github.io/nagoya/

## 지도와 상세 정보

`trip-details.js`는 날짜별 장소, 일본어 정식 명칭, 추천 메뉴, 한국어 후기 및 Google Maps 링크를 제공합니다. 번호 핀 지도는 Leaflet과 OpenStreetMap을 사용하며 실제 이동은 장소별 Google Maps 대중교통·도보 링크를 사용합니다. Maps 공식 URL은 휴대폰에 앱이 설치되어 있으면 앱으로 연결되며 기기 설정에 따라 웹으로 열릴 수 있습니다. `guide.html`은 JavaScript 없이 읽는 전체 일정입니다.

토요일은 07:30 모닝 후 08:30 출발, 11:00 대창고 표를 전제로 합니다. 오아시스21 옥상은 2026.11.04~2027.04.30 예정 공사 폐쇄를 반영했습니다.

## 모바일 UX

기본 화면은 시간별 일정이며 날짜별 지도는 별도 보기로 전환합니다. 날짜와 보기 상태는 URL에 반영되고 마지막 날짜와 식당 필터는 브라우저에 저장됩니다. 지도는 필수 동선과 선택 관광지를 구분하며, 각 장소에는 추천 메뉴·예약·후기·Maps 바로가기를 제공합니다. `ux.js`와 `ux.css`는 상태 유지, 지도 대체 경로, 접근성 및 모바일 터치 영역을 담당합니다.

## 번호 핀 지도

`numbered-map.js`는 하루의 장소를 한 지도에 번호로 표시합니다. 가까운 핀은 겹치지 않도록 화면에서 분리하고 가는 선으로 실제 좌표를 연결합니다. 전체·시내·지브리 확대, 선택 장소 표시 전환, 장소 목록과 팝업의 Google Maps 앱 연결을 지원합니다. `map-locations.js`는 2026-11-05 확인한 OpenStreetMap 장소 및 국토지리원 주소 검색 좌표와 원본 출처를 담습니다. 주소 및 구역 중심점은 실제 출입구와 차이가 있습니다. 국토지리원 주소 검색 결과를 위경도 형식으로 가공했습니다. Leaflet 1.9.4와 라이선스는 `vendor/leaflet`에 포함하며 타일은 OSM 사용 정책에 따라 요청합니다.
